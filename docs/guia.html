Glasshouse — Guía interactiva

Instalación

Glasshouse está pensado para vivir en ~/dotfiles. La sesión y muchos scripts asumen esa ruta.

Requisitos

  • Arch Linux + Hyprland (Wayland). Sesión basada en Lua (hypr/.config/hypr/session.lua).
  • Componentes: Waybar, SwayNC, Rofi, Kitty, nwg-dock-hyprland, Hyprlock/Hypridle, grim/slurp/wl-clipboard, wpctl (PipeWire), brightnessctl, etc.
  • Fuentes SF Pro / SF Mono no se redistribuyen; --with-fonts usa una copia local si existe.

Instalación rápida (usuario)

git clone <URL-DEL-REPOSITORIO> ~/dotfiles
cd ~/dotfiles
./install.sh --dry-run --verbose   # revisar plan
./install.sh --yes                 # aplicar (solo nivel de usuario, sin sudo)

El modo por defecto crea enlaces simbólicos, genera valores de ejecución (tema, appearance.conf, avatar, apps del dock) y construye Waybar. No usa sudo.

Si el repo no está en $HOME/dotfiles, falla salvo con --allow-nonstandard (los scripts de sesión siguen asumiendo ~/dotfiles).

Opciones generales: --dry-run, --yes, --verbose.

Post-instalación

  • Si instalaste la sesión: elige Hyprland Glass en el greeter (SDDM) o ejecuta hyprland-glass.
  • Idioma y teclado: abre el menú de ajustes → “Idioma y entrada” (requiere --with-localeinput para aplicar cambios de sistema). Tras cambiar locale, cierra sesión para que las apps hereden LANG/LC_*.
  • Recarga componentes si hace falta: pkill -SIGUSR2 waybar, ~/.local/bin/swaync-apply-locale, hyprctl reload.
Backups y desinstalación
  • Backups de usuario: ~/.dotfiles-backup/install-<timestamp>/ (con manifest.txt) cuando hay algo que respaldar.
  • SDDM: /var/backups/sddm-themes/glass.<ts> y /etc/sddm.conf.bak.<ts>.
  • PAM (--with-fingerprint/--with-lockout): /etc/pam.d/sddm.bak.<ts>, /etc/pam.d/hyprlock.bak.<ts>.
  • Desinstalar enlaces de usuario: ./uninstall.sh --dry-run / --yes (solo symlinks al repo bajo $HOME; no revierte cambios de sistema).

Uso rápido

Atajos útiles

  • Super + Espacio: lanzador de apps (rofi-drun).
  • Super + ,: panel de ajustes.
  • Super + /: visor de atajos (keybinds-viewer).
  • Super + L: bloquear pantalla.
  • Ctrl + Alt + Supr: menú de energía.
  • Super + K: cambiar layout de teclado.

Los atajos exactos dependen de keybindings.conf|.lua y userprefs.

Tema claro/oscuro

~/.local/bin/theme-toggle alterna ~/.config/theme/mode y propaga current.* a GTK, iconos, Kvantum, Waybar, SwayNC, Kitty y dock.

Waybar / SwayNC

Reconstruir/reiniciar Waybar: ~/.local/bin/waybar-build / ~/.local/bin/waybar-restart.

Aplicar idioma de SwayNC: ~/.local/bin/swaync-apply-locale (usa LC_MESSAGES/LANG).

Idioma y entrada

Desde Ajustes → “Idioma y entrada” (helper con polkit). Aplica locale (localectl set-locale, LC_* consistentes) y layouts/atajo de cambio en Hyprland + persistencia.

Importante Cierra sesión para que toda la sesión herede el nuevo idioma.

Solución de problemas

Casos reales vistos en esta configuración y cómo resolverlos.

Desinstalar HyDE rompió la sesión (faltan configs de Hyprland) crítico

Síntoma: tras ejecutar el desinstalador de HyDE desaparecen ~/.config/hypr/hyprland.conf, keybindings.conf, userprefs.conf, etc., o $HYPRLAND_CONFIG apunta a un archivo antiguo de HyDE. La sesión puede fallar al reiniciar.

Causa: el script de desinstalación de HyDE elimina configs vivas.

Solución: Glasshouse usa la config del repo; restaura desde el repo y corrige $HYPRLAND_CONFIG:

REPO=~/dotfiles/hypr/.config/hypr
cp -a "$REPO"/{hyprland.conf,hyprland.lua,keybindings.conf,keybindings.lua,userprefs.conf,userprefs.lua,monitors.conf,monitors.lua,windowrules.conf,windowrules.lua,hypridle.conf,hypridle.lua,hyprlock.conf} ~/.config/hypr/
# si HYPRLAND_CONFIG apunta a ~/.local/share/hypr/hyprland.conf:
mkdir -p ~/.local/share/hypr && cp -a "$REPO/hyprland.conf" ~/.local/share/hypr/hyprland.conf
hyprctl configerrors

La sesión hyprland-glass carga ~/dotfiles/hypr/.config/hypr/session.lua; evita depender de ~/.local/share/hyde.

El menú de energía no abre desde Waybar común

Diagnóstico: ejecútalo en terminal para ver el error:

~/.local/bin/power-menu

Causa vista: UnboundLocalError por variable no definida (p. ej. title_shadow) en una rama de load_css().

Solución: corrige el script en scripts/.local/bin/power-menu (symlink en ~/.local/bin/power-menu), valida con python3 -m py_compile ... y vuelve a abrir. Revisa también que existan ~/.config/theme/current.css y mode.

El contador de bloqueo por contraseña se acumula al desbloquear con huella común

Síntoma: fallas la contraseña, desbloqueas con huella y al volver a bloquear el retardo/contador es mayor.

Causa: en Hyprlock la huella es nativa (fprintd) y no pasa por PAM, así que pam_faillock authsucc no limpia el tally.

Solución: limpiar el tally tras un desbloqueo exitoso: glasshouse-pam-cooldown --reset (modo --reset en scripts/system/pam/pam-cooldown, instalado en /usr/local/bin/glasshouse-pam-cooldown) llamado desde scripts/.local/bin/lock-screen al salir hyprlock con éxito.

sudo install -m 755 ~/dotfiles/scripts/system/pam/pam-cooldown /usr/local/bin/glasshouse-pam-cooldown
# verificar:
faillock --conf /etc/security/faillock-lockscreen.conf --dir /run/faillock-lockscreen --user "$USER"

En SDDM, si pam_fprintd salta a authsucc en la pila, el reseteo ocurre por PAM.

Blueman u otras apps no cambian de idioma sin cerrar sesión

Causa: las apps GTK/Qt heredan el entorno (LANG/LC_MESSAGES) al iniciarse y usan sus catálogos de traducción instalados.

Solución: configura el locale del sistema (Ajustes → Idioma y entrada o localectl) y cierra sesión e inicia de nuevo. Prueba puntual: LC_MESSAGES=en_US.UTF-8 blueman-manager. Algunas apps dependen de tener el paquete de idioma instalado.

SwayNC no tiene estilo glass o idioma esperado
  • Config/estilo en vivo: ~/.config/swaync/ (puede diferir del repo). Respalda antes de cambiar.
  • Aplicar idioma según sesión: ~/.local/bin/swaync-apply-locale (genera ~/.config/swaync/config.json y recarga).
  • Assets del repo: swaync/.config/swaync/style.css, config.{en,es}.json, lanzador swaync-run.
  • El estilo glass usa tokens de ~/.config/theme/current.css (evita dependencias wallbash/HyDE).
El logo o Super+Espacio no abre el lanzador
  • Wrapper: ~/.local/bin/rofi-drun (symlink al repo). Verifica: command -v rofi-drun, ~/.local/bin/rofi-drun.
  • Waybar: definitions.json/~/.cache/waybar/config.json deben llamar a ~/.local/bin/rofi-drun. Recarga Waybar: pkill -SIGUSR2 waybar o ~/.local/bin/waybar-restart.
  • Atajo: revisa hypr/.config/hypr/keybindings.conf|.lua o userprefs.conf|.lua (p. ej. Super+Space).
Terminal sin apariencia / error de fastfetch tras cambios o desinstalar HyDE
  • Kitty: config en repo kitty/.config/kitty/kitty.conf (incluye ~/.config/theme/current.kitty). Enlaza: ln -sfn ~/dotfiles/kitty/.config/kitty ~/.config/kitty o vía install.sh.
  • Fastfetch: si ~/.config/zsh/user.zsh llama a ~/.config/fastfetch/random-fetch.sh y falta, restaura ~/.config/fastfetch/ (respaldo o config propia) o ajusta el script de inicio.
  • Prompt (Starship): si STARSHIP_CONFIG apunta a un archivo inexistente, se usa la config por defecto. Restaura ~/.config/starship/starship.toml si aplica.
  • Abre una nueva terminal para aplicar cambios.
Dolphin/Qt perdió apariencia

Revisa/restaura: ~/.config/dolphinrc, ~/.config/kdeglobals, ~/.config/qt5ct, ~/.config/qt6ct, ~/.config/Kvantum, ~/.config/gtk-3.0. El tema se propaga con theme-toggle/scripts de tema; reinicia Dolphin/apps Qt tras cambios.

El menú de energía no tiene blur/glass como otros paneles

Añade reglas de capa para el namespace powermenu en hypr/.config/hypr/windowrules.conf y windowrules.lua:

layerrule = blur true,match:namespace powermenu
layerrule = ignore_alpha 0,match:namespace powermenu

Recarga Hyprland (hyprctl reload) y vuelve a abrir el menú.

¿Qué config carga la sesión?

La sesión Glasshouse usa el repo, no ~/.config/hypr como fuente principal:

/usr/local/bin/hyprland-glass
  -> start-hyprland -- -c ~/dotfiles/hypr/.config/hypr/session.lua

session.lua carga hyprland.lua y daily.lua. Edita en ~/dotfiles/hypr/.config/hypr/ para cambios persistentes en el dotfile. Nota: $HYPRLAND_CONFIG puede apuntar a ~/.local/share/hypr/hyprland.conf en tu instalación; mantenlo coherente.

Personalización: rutas y archivos

Dónde tocar para adaptar Glasshouse a tu gusto. Prefiere editar en el repo (~/dotfiles) y, si aplica, recargar o re-symlink con ./install.sh --yes.

Idioma de componentes propios

Lanzador, SwayNC, visor de atajos y selectores siguen LC_MESSAGES/LANG (ES/EN). El menú de ajustes usa un diccionario interno. El locale del sistema se persiste con localectl (vía helper) y requiere re-login para propagarse a la sesión.

Recargar tras cambios
  • Hyprland: hyprctl reload (algunos cambios en modo Lua o binds pueden requerir reiniciar sesión).
  • Waybar: ~/.local/bin/waybar-restart o pkill -SIGUSR2 waybar.
  • SwayNC: ~/.local/bin/swaync-apply-locale o swaync-client --reload-config --reload-css.
  • Symlinks/configs de usuario: ./install.sh --yes.
